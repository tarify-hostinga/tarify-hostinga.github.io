Docker в Таймвеб Клауд: вопросы и ответы

Ниже короткие ответы на 4 частых вопроса и главные данные с датой проверки. Подробный разбор с инструментом: Docker в Таймвеб Клауд.

Короткие ответы

  • Есть ли у Таймвеб зеркало Docker Hub? Да, бесплатное: dockerhub.timeweb.cloud.
  • Можно ли запустить Docker на обычном хостинге Таймвеб? Нет.
  • Поддерживает ли платформа приложений docker-compose? Пока нет, только Dockerfile.
  • Сколько стоит сервер с Docker? От 1 920 ₽ в месяц, образ Docker из маркетплейса без доплаты за ПО.

Главные данные

  • Адрес зеркала: https://dockerhub.timeweb.cloud
  • Файл на Linux: /etc/docker/daemon.json
